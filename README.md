# Student-Success-Early-Warning

DS-311 Data Mining Project (Fall 2026), NUST. Early-warning system to predict student dropout and academic success using machine learning.

## Problem
Can we identify students at risk of dropping out early enough for advisors to help, and which patterns show up before dropout?

## Dataset
- **Primary:** UCI "Predict Students' Dropout and Academic Success" (id 697), 4,424 students, 36 features, classes: Dropout / Enrolled / Graduate. License: CC BY 4.0.
  - Realinho, V., Machado, J., Baptista, L., Martins, M. V. (2022). Predicting Student Dropout and Academic Success. *Data*, 7(11), 146. https://doi.org/10.3390/data7110146
- **Optional expert module:** OULAD. Kuzilek, J., Hlosta, M., Zdrahal, Z. (2017). Open University Learning Analytics dataset. *Scientific Data*, 4:170171. https://doi.org/10.1038/sdata.2017.171
