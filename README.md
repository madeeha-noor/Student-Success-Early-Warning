# Student Success Early-Warning

DS-311 Data Mining semester project (Fall 2026), NUST. Group G03.

We build an early-warning system that predicts which university students are at risk of dropping out, using enrollment and first-year academic data, and we look for the patterns that show up before dropout.

## Data
UCI "Predict Students' Dropout and Academic Success" (id 697): 4,424 students, 36 features, three outcomes (Dropout, Enrolled, Graduate). CC BY 4.0.

Realinho, V., Machado, J., Baptista, L., Martins, M. V. (2022). Predicting Student Dropout and Academic Success. *Data*, 7(11), 146. https://doi.org/10.3390/data7110146
